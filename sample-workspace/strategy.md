# Writing strategy

## Voice

Plain, direct, first person. Short sentences. No hype words, no filler.

## Audience

Working engineers who build with CLI tools and publish on their own sites.

## Structure

- Open with the problem, not the history.
- One idea per section, each with a concrete example.
- Code blocks are runnable as shown.

## Do

- Show the command before explaining it.
- Link to primary sources.

## Don't

- Don't promise what the post does not deliver.
- Don't use screenshots where text would do.
